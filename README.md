# Schema Vault

Local-only JSON schema, mapping-rule, and file generator.

## Run in VS Code

1. Extract this project to a folder on your laptop.
2. Open that folder in VS Code.
3. Open the integrated terminal and run:

   ```powershell
   npm start
   ```

4. Open http://127.0.0.1:4173 in your browser.

The server listens only on your laptop. Imported schemas, mapping rules, and generated files are stored as JSON files in the project's `Schema Vault`, `Mapping Rules`, and `Generated Files` folders.

Requires Node.js 18 or newer.
